| Technique                | What to recognise                             | Typical DS        | Complexity         |
| ------------------------ | --------------------------------------------- | ----------------- | ------------------ |
| Two Pointers             | Work from both ends / compare pairs           | Array/String      | O(n)               |
| Sliding Window           | Contiguous subarray/substring                 | Array/String      | O(n)               |
| Hashing                  | Fast lookup/counting                          | HashMap/HashSet   | O(n)               |
| Prefix Sum               | Repeated range-sum queries                    | Array             | O(n) preprocessing |
| Stack                    | Previous/next greater, matching               | Stack             | O(n)               |
| Queue                    | FIFO / BFS                                    | Queue/Deque       | O(n)               |
| Monotonic Stack          | Next greater/smaller                          | Stack             | O(n)               |
| Binary Search            | Sorted/searchable answer space                | Array             | O(log n)           |
| Heap                     | Top-K / min-max selection                     | PriorityQueue     | O(n log k)         |
| Recursion                | Break problem into smaller identical problems | Tree/Backtracking | varies             |
| Backtracking             | Try → recurse → undo                          | Array/String/Tree | exponential        |
| Linked List manipulation | Reverse/merge/detect cycle                    | LinkedList        | O(n)               |
| Tree DFS                 | Explore recursively                           | Tree              | O(n)               |
| Tree BFS                 | Level/order traversal                         | Queue             | O(n)               |
| Graph DFS/BFS            | Reachability/components                       | Graph             | O(V+E)             |
| Dynamic Programming      | Overlapping subproblems                       | Array/Matrix      | varies             |
| Greedy                   | Locally optimal decision                      | Array/intervals   | varies             |
| Sorting + scanning       | Sort first, then simplify                     | Array             | O(n log n)         |
